# Personal Website with CI/CD

A simple personal website demonstrating automated testing and deployment using GitHub Actions and GitHub Pages.

## 🌐 Live Demo
Visit the live site: [https://hr934694.github.io/website-demo/](https://hr934694.github.io/website-demo/)

## ⚙️ Features
- **HTML5 & CSS3:** Responsive personal profile card layout
- **JavaScript:** Dynamic current year and smooth load animations
- **Continuous Integration (CI):** Validates required files and HTML structure on every push/PR
- **Continuous Deployment (CD):** Deploys verified builds to GitHub Pages automatically
